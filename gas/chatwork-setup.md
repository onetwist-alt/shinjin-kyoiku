# チャットワーク通知の設定手順

新人教育アプリから、チャットワークのルームに通知を送るための設定です。
所要時間は10分ほど。パソコンで作業してください。

---

## 全体の流れ

```
アプリ（日報の提出など）
   ↓ 送信
GAS（Google Apps Script）… APIトークンはここに保管
   ↓ チャットワークAPI
チャットワークのルームに投稿
```

アプリに直接トークンを書くと、公開しているファイルから誰でも読めてしまいます。
そのため GAS を間に挟み、トークンは GAS の中だけに置きます。

---

## ステップ1：チャットワークの API トークンを取得

1. チャットワークにログインし、右上のアイコン →「サービス連携」
2. 左メニューの「API Token」を開く
3. パスワードを入力すると、英数字のトークンが表示されるのでコピー

## ステップ2：ルーム ID を調べる

1. 通知したいルーム（グループチャット）を開く
2. ブラウザのアドレスバーを見る
   例：`https://www.chatwork.com/#!rid123456789`
3. `rid` のうしろの数字（この例では `123456789`）がルーム ID

## ステップ3：GAS を作る

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初から入っているコードを全部消し、`chatwork-relay.gs` の中身を貼り付ける
3. プロジェクト名を「新人教育アプリ チャットワーク通知」などに変更
4. 左メニューの歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ `CHATWORK_TOKEN` / 値：ステップ1のトークン
   - プロパティ `ROOM_ID` / 値：ステップ2のルーム ID
   - 「スクリプト プロパティを保存」

## ステップ4：ウェブアプリとして公開

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車マーク →「ウェブアプリ」を選ぶ
3. 設定
   - 説明：任意
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ 初回は Google アカウントの承認画面が出るので許可
   （「このアプリは確認されていません」と出たら「詳細」→「安全ではないページに移動」）
5. 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

## ステップ5：アプリに設定

1. 責任者画面 →「設定」タブ →「チャットワーク通知」
2. 「通知を使う」にチェック
3. ステップ4の URL と、ステップ2のルーム ID を入力
4. 通知する内容を選ぶ（日報の提出／責任者の記録／上長コメント）
5. 「通知の設定を保存」を押す
6. 「テスト送信」を押して、チャットワークに届くか確認

---

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| テスト送信が「送信できませんでした」 | デプロイ設定の「アクセスできるユーザー」が「全員」になっているか |
| 何も届かない | GAS のエディタで `testSend` を実行し、ログのエラー内容を確認（トークンやルームIDの間違い） |
| 一部だけ届かない | 設定画面のチェック（どのイベントを通知するか）を確認 |
| コードを直したのに反映されない | 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→ デプロイ |

## 補足

- 通知の文面を変えたいときは、アプリ側（`js/employee.js` / `js/admin.js` の `notifyChatwork(...)` の部分）を編集します。
- 通知が不要になったら、設定画面の「通知を使う」のチェックを外すだけで止まります。
- GAS の無料枠は1日あたり2万回の外部通信まで。この用途では十分です。
